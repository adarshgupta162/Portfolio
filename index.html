Projects

PhyNetix

JEE test-series platform, being built for the JEE Main 2027 cycle

Students take computer-based tests that look and behave like the real NTA exam, then review how they did. I'm building the test interface, the question bank and the admin tools behind it.

  • The test screen follows the real JEE Main layout, including the question palette shapes, colours and section tabs.
  • Questions arrive through Excel import templates. I convert LaTeX sources into the template columns with Python (openpyxl, pandas) and check each file before import.
  • I also explored exam proctoring with camera, microphone and screen-share monitoring, and prototyped a dedicated admin panel.

Stack: React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Supabase

ShreekinOS

CRM and ERP for Shreekin Life Sciences, a pharmaceutical company

Software for a pharma company's field team: who can see what, who reports to whom, who is on the ground, and how visits get planned.

  • Role-based access control, with each role routed to its own screens after login and data protected by Row-Level Security policies.
  • A manager and employee hierarchy across regions, zones and territories.
  • Sales workflows, field attendance and joint field-visit planning with business rules, plus a video-conferencing module that has a live reporting panel built in.

Stack: React, Supabase, PostgreSQL, Edge Functions, Row-Level Security
